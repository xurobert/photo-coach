# Photo Coach MVP（本地选片助手）

本地优先的摄影师工具：选片去重、质量打分、基础检测、个人趋势建议、模糊语义检索。第一版不做自动修图引擎。

## 目标用户
业余/半专业摄影师（人像、cos、风景、花卉），希望免费本地完成挑图与回顾，并得到可执行的提升建议。

## 第一版范围（做）
1. **导入扫描**：选择本地文件夹，索引 JPG/HEIC/PNG（RAW 可后置，先读 sidecar/嵌入预览若可得）。
2. **去重选片**：感知哈希分组相似连拍；每组保留建议最佳（清晰度 + 曝光启发式）。
3. **打分**：无强制云端模型；默认本地启发式（清晰度/曝光/对比）。可选接入本地视觉模型接口（OpenAI-compatible / Ollama）做审美分，插件化。
4. **检测**：过曝/欠曝、明显模糊；人像场景可选「疑似闭眼」占位接口（模型可选）。
5. **趋势建议**：基于 EXIF 聚合（焦段、光圈、时段、题材标签若有），输出 3–5 条可执行建议（例如「本月 70% 人像在 35mm，可刻意练 85mm 半身」）。
6. **语义检索（知识库）**：导入时生成图片向量（本地 CLIP 或轻量 embedding）；支持中文模糊提示词检索，如「雨天红伞」「棚拍侧光」；结果按相似度排序并回链文件路径。
7. **CLI + 简单本地 Web UI**：能扫目录、看候选、搜索、看建议报告。

## 明确不做（第一版）
- 完整修图（曲线、蒙版、RAW 显影）
- 云端账号体系 / 付费订阅
- 自动发帖到 X
- 替用户删除原片（只标记建议删除，需确认）

## 技术倾向
- 语言：Python
- 元数据：Pillow / piexif 或 exiftool
- 去重：imagehash
- 向量库：本地 sqlite + 向量扩展，或 chroma / faiss 本地模式
- UI：FastAPI + 极简前端，或 Streamlit（优先易演示）
- 配置：YAML；模型 endpoint 可空（纯启发式模式必须能跑）

## 成功标准
- 空模型配置下：能扫描样例目录、去重分组、打分排序、生成趋势建议 Markdown
- 配置本地 embedding 后：中文模糊查询能找回相关图
- README 含：一句话定位、GIF/截图位、安装、示例命令、与 Lightroom 的边界说明
- 公开仓库适合拿 star：英文+中文 README 均可，About 描述清晰
